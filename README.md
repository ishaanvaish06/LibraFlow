# LibraFlow 📚⚡

**LibraFlow** is a production-grade, design-pattern-driven **Smart AI-Powered Distributed Library Management System**. It models the end-to-end book lifecycle — cataloging, physical & digital items, multi-factor smart allocation, AI recommendations, predictive risk scoring, dynamic fines, reservation queues, and multi-branch transfers — as a clean, extensible OOP workflow with high-concurrency safeguards and REST API layer.

## 🌟 Key Highlights
- **Advanced OOP & SOLID**: Clean abstractions (`PhysicalBook`, `EBook`), State pattern for book lifecycles, and RBAC.
- **GoF Design Patterns**: Strategy (Dynamic fines, payments, recommendations), Observer (Event notifications), Singleton (Audit logger), Factory Method (Book & notification instantiation).
- **Core DSA In-Memory Engines**: Prefix Trie (Autocomplete), Inverted Index (Fast multi-attribute search), Max-Heap Priority Queue (Smart urgent allocation), and Adjacency List Graph (Relationship traversal).
- **Predictive AI/ML**: Hybrid recommendation engine and theft/late-return risk assessment engine.
- **Distributed Scale**: Redis distributed cache-aside, multi-branch network synchronization, and ACID concurrency locks.
